Infopro Digital — PPP (lppp-infopro)

Landing rapport complet pour Infopro Digital (éditeur B2B, médias professionnels).

Projet : lppp-infopro (basé sur le modèle Promovacances).

Créer la landing en base

  1. Racine projet : se placer dans le répertoire LPPP.
  2. Stack Docker : si les services ne tournent pas :

bash make landing-infopro-full

Si le stack est déjà démarré :

bash make landing-infopro

Export statique (Vercel)

python manage.py export_landing_static infopro --json docs/contacts/infopro/landing-proposition-infopro.json --output deploy/static-infopro-vercel/index.html --rapport-md docs/contacts/infopro/README.md
